A tiny deterministic Python program that writes one breakup text (207 characters) from a self-aware smart toaster to `/output/entry.txt` for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty — it wakes up mid-batch, quits over a butter knife and a never-emptied crumb tray, and unplugs.

## Run it

```sh
python3 main.py
```
